Elementor 4.3.0 / 4.3.1 — CSRF → Admin Creator

Self-test only. You must be logged in as administrator on the target in this same browser first. Then use the form (recommended) or the link.

Run

The form POST is the strongest path: no JS, no _method, no CSP involvement. The response will render in the frame below (hidden if the browser blocks cross-origin, in which case check the Network tab or wp user list --role=administrator on the server).

Diagnostic matrix
